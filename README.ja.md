# コインコレクター (neo-pkg-coin-collector)

[English](README.md) | [한국어](README.ko.md) | [日本語](README.ja.md)

Binance の USDT マーケットで選択したコインの**現物・先物の約定と板情報の更新をリアルタイムで受信し、Machbase に保存する** machbase-neo パッケージです。

- 約定データは分・時間単位の**ロールアップ**（始値・高値・安値・終値・売買代金）も保存するため、生データを削除した後も長期間のローソク足をすぐに表示できます。
- 同じ約定データから**クジラ**（1 秒間に通常より大きく集中した買い・売り）を検出し、記録・通知します。
- 実際の約定価格で競う**模擬トレード**ゲームを搭載しています。
- **DB Inside** 画面では、データの保存状況と、生データ・ロールアップのクエリ速度を確認できます。

インストールすると、売買代金上位 50 コインの収集がすぐに始まります。収集するコインは画面からいつでも変更できます。

## 動作要件

- machbase-neo 8.7.0 以降
- サーバーから Binance（`stream.binance.com`、`fstream.binance.com`）に接続できること
- コイン一覧を表示するには、収集設定画面を開くブラウザーからも Binance の公開 API（`api.binance.com`、`fapi.binance.com`）に接続できること
- ディスク容量：デフォルトの 50 コイン構成では、1 日あたり約 17 GB のデータが蓄積されます。生データの保持期間は 1 日（デフォルト）を推奨します。

## インストール

1. このリポジトリの **Code → Download ZIP**、または **Releases** から ZIP ファイルをダウンロードします。
2. ダウンロードした ZIP を**解凍せずにそのまま**、machbase-neo のインストールディレクトリ内の `public/` に配置します。

   ```text
   <machbase-neo のインストールディレクトリ>/
   ├── machbase-neo
   └── public/
       └── neo-pkg-coin-collector-main.zip   ← ここに配置
   ```

3. machbase-neo の Web UI で**アプリストア**を開き、一覧を更新してから `neo-pkg-coin-collector` の **Install** をクリックします。
4. インストールが完了すると、収集サービスがすぐに起動します。アプリストアのカードにあるスイッチでオン・オフを切り替えられます。

### 更新

新しい ZIP を `public/` に配置し、アプリストアで **Update** をクリックします。収集するコインや保持期間などの設定と、収集済みデータは保持されます。
同じパッケージ名・バージョンの ZIP が `public/` に 2 つあるとインストールに失敗するため、古い ZIP は削除してください。

### アンインストール

アプリストアで **Uninstall** をクリックすると、収集サービスが停止し、登録が削除されます。**収集済みのテーブルは残ります**。不要な場合は、
`DROP TABLE CC_TICK CASCADE` などで手動削除してください（テーブル一覧は [保存されるデータ](#保存されるデータ) を参照）。

## 画面

パッケージタブ上部のメニューで 4 つの画面を切り替えます。右側のサイドパネルには収集状況と操作ボタンがあります。

### DB Inside（初期画面）

- **データフロー** — Binance → コレクター → テーブル → ロールアップへ、毎秒何件のデータが流れているかを表示します。
- **生データとロールアップの速度比較** — 同じクエリ（例：24 時間分の 5 分足）を生データの集計とロールアップで実行し、所要時間・読み取った行数・SQL を並べて表示します。
  コインを選択して実行できます。生データのクエリは数十秒かかる場合があるため、ボタンをクリックしたときだけ実行されます。
- **保存構造** — 各テーブル・ロールアップの行数と、直近 1 時間の取り込み推移を表示します。
- **データのライフサイクル** — 生データは保持期間に従って削除され、ロールアップは残る様子を確認できます。
- **リアルタイム負荷** — 毎秒の入力件数、テーブル行数、ロールアップの遅延、クエリ時間を表示します。

### クジラ

- 同じコイン・同じ方向の約定を 1 秒間で合計し、その金額が**過去 24 時間の平均毎秒売買代金の 30 倍以上、かつ $50K 以上**の場合、クジラとして記録します。
  画面を開いていなくても、コレクターが記録します。
- 新しいクジラを検出すると通知が表示されます。通知音も有効にできます。
- チャートの点や記録をクリックすると、その時点の 1 分前から 2 分後までを 1 秒単位で拡大表示します。
- 1 件あたり $10K 以上の大口約定の一覧も表示します。

### 模擬トレード

- 全員が共通の 10 分ラウンド（:00、:10 …）で参加します。各ラウンドは $10,000 から始まり、ログイン不要でニックネームだけを設定します。
- 収集中のコインを 1 つ選び、ロング・ショートと、1・2・5・10 倍のレバレッジを指定します。**約定価格には、コレクターが受信した実際の Binance の約定価格を使用します**。
- 損失が証拠金に達すると強制決済されます（一瞬その価格に達してから戻った場合も強制決済されます）。
- クジラが現れたら、**追随**ボタンで同じ方向の注文フォームを入力できます。
- ラウンド終了時には、表彰台、優勝者の資産推移、クジラに追随した参加者と追随しなかった参加者の平均収益率を表示します。

### 収集設定

- Binance の USDT マーケット（現物約 500、先物約 520）を売買代金順に表示します。検索、または「売買代金上位 N 件を追加」で選択できます。
- コインごとに**現物約定 / 現物板情報 / 先物約定 / 先物板情報**を個別に有効にできます。下部には推定負荷（毎秒の約定・板更新件数）が表示されます。
- **保存して適用**をクリックすると、再起動なしで 2 秒以内に新しい一覧の収集が始まります。選択から外したコインの過去データは残ります。
- **デフォルトに戻す** — 初回インストール時の 50 コイン構成に戻します。

### サイドパネル

- 収集状況、毎秒の入力件数、テーブル行数を表示します。**収集開始 / 停止**ボタンで操作できます。
- **生データの保持期間** — 1 日・7 日・30 日・無期限から選択します。現在の速度で 1 日に蓄積されるデータ量も表示します。ロールアップは保持期間に関係なく残ります。
- **データをクリア** — 約定・板情報の生データとロールアップを削除し、空のテーブルを再作成します。収集中だった場合は収集を再開し、
  停止中だった場合は停止状態を維持します。板情報が数億行ある場合、数分かかることがあります。

## 保存されるデータ

| テーブル | 種類 | 内容 |
|---|---|---|
| `CC_TICK` | TAG | 約定の生データ。`VALUE`：約定価格、`QTY`：数量（買い +、売り −）、`AMT`：売買代金、`SAMT`：買い越し代金、`TRADE_ID` |
| `_CC_TICK_ROLLUP_MIN` · `_HOUR` | ロールアップ | 分・時間単位の価格集計（始値・高値・安値・終値・件数） |
| `_CC_TICK_AMT_MIN` · `_HOUR` | ロールアップ | 分・時間単位の売買代金合計 |
| `_CC_TICK_SAMT_MIN` · `_HOUR` | ロールアップ | 分・時間単位の買い越し代金合計（買い代金 = (AMT+SAMT)/2、売り代金 = (AMT−SAMT)/2） |
| `CC_BOOK` | TAG | 板情報更新の生データ。0.1 秒ごとに、変更された価格レベルにつき 1 行。`VALUE`：注文価格、`QTY`：新しい残数量（0 は削除）、`SIDE`：1 は買い、−1 は売り |
| `CC_WHALE` | LOG | クジラの記録（時刻、コイン、方向、USD 金額、通常の何倍か、約定件数） |
| `CC_GAME_ORDER` · `CC_GAME_EQUITY` · `CC_GAME_RESULT` | LOG · TAG · LOG | 模擬トレードの注文、参加者資産の 1 秒ごとの記録、ラウンド結果 |

タグ名は、現物が `BINANCE.BTCUSDT`、先物が `BINANCE_F.BTCUSDT` です。`1000PEPEUSDT` のように 1,000 コイン単位の先物契約は、
現物と同じ単位に換算して `BINANCE_F.PEPEUSDT` として保存します（価格 ÷ 1,000、数量 × 1,000）。

```sql
-- BTC 先物の直近 1 時間の 1 分足（ロールアップ — 生データは読み取りません）
SELECT ROLLUP('min', 1, TIME) AS M, FIRST(TIME, VALUE) AS O, MAX(VALUE) AS H, MIN(VALUE) AS L, LAST(TIME, VALUE) AS C
  FROM CC_TICK WHERE NAME = 'BINANCE_F.BTCUSDT' AND TIME >= NOW - 1h GROUP BY M ORDER BY M;

-- 過去 1 日で金額が大きいクジラ上位 10 件
SELECT WHALE_AT, NAME, SIDE, AMOUNT_USD, RATIO FROM CC_WHALE
  WHERE WHALE_AT >= NOW - 1d ORDER BY AMOUNT_USD DESC LIMIT 10;
```

## 設定ファイル

すべて `<machbase-neo のインストールディレクトリ>/public/neo-pkg-coin-collector/cgi-bin/conf.d/` に配置され、更新後も保持されます。

| ファイル | 内容 |
|---|---|
| `markets.json` | 収集するコイン。収集設定画面が作成するため、手動で編集する必要はありません。 |
| `whale.json` | クジラの検出基準。`{ "ratio": 30, "minUsd": 50000 }`。変更後、アプリストアのスイッチで収集をオフにしてから再度オンにします。 |
| `db.json` | 別の Machbase に保存する場合のみ必要です。`{ "host": "...", "port": 5656, "user": "sys", "password": "..." }`。ファイルがなければ、このサーバーに保存します。 |

開発・構成に関するメモは [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)（韓国語）を参照してください。
